FABRIC · SERVER-SIDE · JAVA 25

ZYN'S BETTER TEAMS

A server-side Fabric mod for creating and managing persistent teams. Players do not need to install the mod on their own clients.

FABRICMINECRAFT 26.1.x–26.3SERVER-SIDEJAVA 25+DEVELOPMENT COMPLETE

01 / PROJECT STATUS

Development is complete. The three target JARs have been prepared, but they are not attached to a public GitHub release yet. The Modrinth project page has been submitted and is awaiting moderation; it is not published yet.

These are testing builds. Check the game and dependency versions below, and back up your server before testing.

02 / FEATURES

  • Team management. Create, rename and disband teams; invite players, accept or decline invitations and join requests, and manage members.
  • Team chat. Toggle team-only chat and return to global chat when needed.
  • Team settings. Team owners can change the team's label colour and friendly-fire setting.
  • Player tools. View teammate coordinates, set personal aliases for teammates, and toggle the vanilla glowing outline.
  • Configuration. Editable YAML configuration, configurable messages and limits, with /team reload.
  • Optional integrations. Fabric Permissions API, Placeholder API, TABCore and outbound Discord webhook options where supported.

This is a server-side Fabric mod. Install the build that matches the server's Minecraft version and install the matching Fabric API. Fabric Permissions API is bundled in the mod JAR; Placeholder API is optional.

04 / INSTALLATION

  1. Back up your server and world.
  2. Install a Fabric dedicated server for the exact Minecraft target, plus the matching Fabric API.
  3. Once the GitHub test-build prerelease is published and its JAR assets appear, download the build matching the server's Minecraft version. Do not use a mismatched JAR.
  4. Place the JAR in the server's mods/ folder and start the server.
  5. Review config/zyns-better-teams/config.yml after first startup. Use /team reload after editing the configuration.

05 / COMMANDS

Commands are registered under /team. The mod replaces the vanilla scoreboard /team root, so vanilla scoreboard commands such as /team add and /team empty are not included.

/team help /team create <name> /team invite <player> /team join-req <team> /team accept [player] /team decline [player] /team requests /team chat /team lists /team info /team modify /team modify color <color> /team modify friendlyFire <true|false> /team members /team coords <player> /team rename <name> /team transfer <player> /team alias <player> <alias> /team unalias <player> /team kick <player> /team leave /team disband /team glow <true|false>
