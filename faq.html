01 / DOWNLOADS & INSTALLATION

Where do I download a project?

Use the Modrinth link on its project card or documentation page. The Modrinth version list is the source of truth for the latest release and supported game versions.

How do I install a resource pack?

Download the ZIP, place it in Minecraft's .minecraft/resourcepacks folder, open Options → Resource Packs, and enable the pack. If another pack changes the same textures or font, adjust pack priority.

How do I install Carpet Fake Players?

Download the JAR matching your Minecraft server version, stop the Paper or Purpur server, put the JAR in plugins/, then restart. Review the generated configuration before changing server behaviour.

02 / COMPATIBILITY & LICENSING

Which Minecraft versions are supported?

Compatibility varies by project and release. Check the Modrinth Versions tab before downloading; do not assume every project supports the same versions.

Do the resource packs change my server or world?

No. These resource packs change client-side visuals. They do not alter server-side block data or world generation.

Can I redistribute or modify the projects?

Check each project's Modrinth licence and its source repository's LICENSE file. The current resource-pack listings show All Rights Reserved; do not assume reuse permission.

03 / REPORTING ISSUES

How do I report a bug?

Use the issue tracker belonging to the affected project. Include your Minecraft version, loader or server software, project version, relevant mods/plugins, error log and steps to reproduce the problem.
