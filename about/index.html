01 / A LITTLE ABOUT ME

I'm an independent Minecraft developer and creator. I work on both sides of the game: server software that helps communities run smoothly, and client-side projects that improve how the game looks and feels.

Most of my hands-on work is with Java, Fabric, Paper, and Purpur. I like to understand how a feature works under the hood, build it into something usable, then refine the configuration, documentation, and release process so others can actually use it.

This archive is where I keep that work organized. It collects project pages, source repositories, downloads, guides, and updates in one place.

04 / HOW I LIKE TO BUILD

  • Useful first. A feature should solve a real problem or make an experience better.
  • Clear by design. Commands, settings and documentation should make sense to the people using them.
  • Test, then polish. Compatibility, edge cases and performance matter just as much as the main feature.
  • Build in public. Feedback, bug reports and ideas help guide what gets improved next.
