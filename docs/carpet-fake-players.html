01 / OVERVIEW

Carpet Fake Players (the BOT_ZynAyush project) lets server owners and players spawn and manage fake players directly on supported Paper and Purpur servers. Bot ownership checks keep ordinary players from controlling someone else's bots.

Features include persistent bot data and inventories, combat actions, item use, hotbar and offhand controls, custom skins, sneaking, collision, gravity, knockback and saved-bot rejoining.

03 / INSTALLATION

  1. Open the Modrinth project page and download the file matching your server's Minecraft version.
  2. Stop your Paper or Purpur server.
  3. Place the downloaded JAR in the server's plugins/ directory.
  4. Start the server and let the plugin generate its configuration.
  5. Review plugins/PlayerBots/config.yml and adjust limits, physics, persistence and messages as needed.

04 / COMMANDS

The main command is /bot. Common management commands:

/bot spawn [name] /bot kill [name|all] /bot rejoin [name] /bot info <name> /bot hotbar <name> <0-8> /bot offhand <name> <slot> /bot drop <name> /bot sneak <name> on|off /bot skin <name> <player> /bot reload

Combat and item-use controls are also available through /bot attack and /bot use, including single, continuous and interval modes.

See the source README for the complete command syntax and version-specific details.

05 / PERMISSIONS & CONFIG

Permission nodes include bot.*, bot.admin, bot.player, bot.action, bot.use, bot.rejoin and original-bot management nodes. Exact defaults are defined in each version's plugin.yml.

Configuration is generated at plugins/PlayerBots/config.yml. Some settings require a server restart. Review the generated comments before changing behavior.

06 / SUPPORT

When reporting an issue, include Minecraft, Paper/Purpur and Java versions, plugin build, relevant plugins, console errors and reproduction steps.
