PAPER · PURPUR · JAVA

CARPET FAKE PLAYERS

Server-side fake-player bots with ownership controls, configurable limits, persistent inventories, combat and item-use actions, custom skins, and player-like movement.

PAPERPURPURMINECRAFT 26.1–26.3JAVA 25
GET ON MODRINTH ↗SOURCE CODE ↗REPORT A BUG ↗FAQ ↗

01 / OVERVIEW

Carpet Fake Players lets server owners and players spawn and manage fake players on supported Paper and Purpur servers. Each bot has an owner, so players can only control their own bots unless they have the required admin permission.

Features include persistent bot data and inventories, combat actions, item use, hotbar and offhand controls, custom skins, sneaking, collision, gravity, knockback, and saved-bot rejoining.

02 / COMPATIBILITY

Choose the build that matches your server's Minecraft version. Builds are version-specific, and other server platforms are not listed as supported.

03 / INSTALLATION

  1. Open the Modrinth project page and download the file for your server's Minecraft version.
  2. Stop your Paper or Purpur server.
  3. Place the downloaded JAR in the server's plugins/ directory.
  4. Start the server and let the plugin create its configuration.
  5. Review plugins/Carpet Fake Players/config.yml and adjust limits, physics, persistence and messages as needed.

04 / COMMANDS

The main command is /bot. Common management commands:

/bot spawn [name] /bot kill [name|all] /bot rejoin [name] /bot info <name> /bot hotbar <name> <0-8> /bot offhand <name> <slot> /bot drop <name> /bot sneak <name> on|off /bot skin <name> <player> /bot reload

Combat and item-use controls are also available through /bot attack and /bot use, including single, continuous and interval modes.

For full command syntax and version-specific details, see the source README.

05 / PERMISSIONS & CONFIG

Permission nodes include bot.*, bot.admin, bot.player, bot.action, bot.use, bot.rejoin and original-bot management nodes. Exact defaults are defined in each version's plugin.yml.

Configuration is generated at plugins/Carpet Fake Players/config.yml. Some settings require a server restart. Review the generated comments before changing behavior.

06 / SUPPORT

When reporting an issue, include your Minecraft, Paper or Purpur, and Java versions; the plugin build; any relevant plugins; console errors; and steps to reproduce the issue.
