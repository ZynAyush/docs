01 / OVERVIEW

ZeroXFog is the official project name; The project card uses a compact visual label; the published project name is ZeroXFog. It is a Minecraft Java resource pack focused on visibility: it removes distracting fog in the Nether, End and caves while preserving the vanilla visual style.

The published release also includes Sodium shader fog support. The repository's pack/ directory is an extracted published release; it is not described as the original editable authoring project.

02 / FEATURES

  • Reduces dimensional and distance fog.
  • Improves visibility in the Overworld, Nether, End and caves.
  • Includes Sodium shader fog support in the published release.
  • Preserves the familiar vanilla visual style.

03 / INSTALLATION

  1. Download the resource-pack ZIP from Modrinth or the source repository.
  2. Place the ZIP in your Minecraft .minecraft/resourcepacks folder.
  3. Open Minecraft's Resource Packs settings.
  4. Move ZeroXFog into the enabled list.
  5. Check the Modrinth version page for the exact Minecraft versions supported by the release.
