ZEROXFOG

01 / OVERVIEW

ZeroXFog is a Minecraft Java resource pack that reduces distracting fog in the Nether, End and caves while keeping Minecraft's familiar look.

The published release also includes Sodium shader fog support. The repository's pack/ directory is an extracted published release, not the original editable authoring project.

02 / FEATURES

  • Reduces fog caused by distance and dimensions.
  • Improves visibility in the Overworld, Nether, End and caves.
  • The published release includes Sodium shader fog support.
  • Keeps Minecraft's familiar vanilla visual style.

03 / INSTALLATION

  1. Download the resource-pack ZIP from Modrinth or the source repository.
  2. Place the ZIP in your Minecraft .minecraft/resourcepacks folder.
  3. Open Minecraft's Resource Packs settings.
  4. Move ZeroXFog to the enabled list.
  5. Check the Modrinth version page to see which Minecraft versions the release supports.
