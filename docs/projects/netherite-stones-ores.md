# Netherite Stones & Ores

**Type:** Minecraft Java resource pack  
**Latest source-tracked release:** 1.1, published 1 November 2026  
**Links:** [Modrinth](https://modrinth.com/resourcepack/netherite-ores) · [Source and release provenance](https://github.com/ZynAyush/Netherite-Stones-Ores)

Netherite Stones & Ores applies a Netherite Block-inspired appearance to supported stone and ore blocks. It is a visual pack for players who want a consistent netherite-themed look across the affected blocks.

## Features

- **Stone-family texture replacements:** The pack includes block textures for stone, granite, diorite, andesite, tuff, gravel, deepslate and cobbled deepslate.
- **Ore texture replacements:** Supported ore textures include coal, copper, diamond, emerald, gold, iron, lapis and redstone ores, including their deepslate variants where provided.
- **Bedrock appearance:** The pack includes a bedrock texture replacement.
- **Block-state mappings:** The pack includes blockstate JSON for stone, deepslate and bedrock so the replacement assets are assigned to the intended block models.
- **Uniform theme:** The listed replacements use the same Netherite Block visual theme to make the affected stone/ore set visually consistent.

## What it does not do

This is a client-side resource pack. It does not turn blocks into Netherite Block items, change their drops, alter mining speed, change hardness, modify world generation or change the server's block data. Only the rendered appearance is changed.

## Installation

1. Download the ZIP from [Modrinth](https://modrinth.com/resourcepack/netherite-ores/versions).
2. Open Minecraft Java Edition's Resource Packs menu.
3. Select **Open Pack Folder** and place the ZIP inside.
4. Return to Minecraft and enable the pack.
5. Place it above other packs that change the same block textures or blockstates.

## Compatibility and release notes

The source-tracked 1.1 release lists Minecraft Java 1.20–1.21.x and 26.1–26.3. Check the Modrinth Versions page for the precise supported version list and newest build. The repository contains the extracted release under `pack/` and the original ZIP under `releases/1.1/`.

## Troubleshooting

- **Some blocks keep vanilla textures:** Another pack may have higher priority and override the same texture or blockstate.
- **Some ore variants are unchanged:** Check whether that exact block variant is included in the current release and whether another pack overrides it.
- **Pack version warning:** Download the build listed for your Minecraft version rather than forcing an unrelated pack format.
