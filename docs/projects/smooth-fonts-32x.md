# Smooth Fonts 32x

**Type:** Minecraft Java resource pack  
**Latest source-tracked release:** 1.2, published 10 October 2026  
**Links:** [Modrinth](https://modrinth.com/resourcepack/smooth-font-32x) · [Source and release provenance](https://github.com/ZynAyush/Smooth-Fonts-32x)

Smooth Fonts 32x replaces Minecraft's default font presentation with a clean, smooth 32x-style font while retaining a familiar vanilla interface. Its purpose is to make text across the game UI easier to read and visually more consistent.

## Features

- **Default font replacement:** Overrides the default Minecraft font definition so the pack's custom glyph textures are used in place of the standard font atlas.
- **Chat readability:** Changes the text appearance used in chat, making the interface typography more consistent with the pack's smooth style.
- **Menu and HUD typography:** The replacement applies to the game's default font usage, so menus and other UI elements that use the default font inherit the new appearance.
- **Unicode glyph coverage:** The release includes the standard ASCII font atlas plus a broad set of Unicode page textures, supporting more than just basic English characters.
- **32x visual treatment:** The pack is presented as a 32x-style font resource pack while preserving the familiar Minecraft look rather than replacing the full UI theme.

## What it does not do

It does not add new gameplay mechanics, change chat features, translate text, or modify server-side data. It changes the client-side rendering of glyphs. A mod or another resource pack that supplies its own font definitions may override or partially replace these changes.

## Installation

1. Download the ZIP from [Modrinth](https://modrinth.com/resourcepack/smooth-font-32x/versions).
2. Open Minecraft Java Edition's Resource Packs menu.
3. Select **Open Pack Folder** and place the ZIP inside.
4. Return to the game, enable Smooth Fonts 32x and place it above other packs that replace the same font files.
5. Check chat, menus and language characters you commonly use.

## Compatibility and release notes

The source-tracked 1.2 release lists Minecraft Java 1.20–1.21.x, snapshots and 26.1–26.3. Always check Modrinth's Versions page for the precise list and current release. The repository's `pack/` directory is an extracted copy of the published pack, not the editable font authoring project. The original ZIP is retained in `releases/1.2/`.

## Troubleshooting

- **Font did not change:** Confirm the pack is enabled and placed above other font packs.
- **Only some text changed:** Some mods and resource packs provide their own font definitions and can override the default font.
- **Missing or unusual characters:** Test the language/character set in question and check the current release notes for compatibility.
- **Pack format warning:** Install the release matching your Minecraft version from Modrinth.
