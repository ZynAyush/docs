# Smooth Fonts 32x

**Type:** Minecraft Java resource pack  
**Latest source-tracked release:** 1.2, published 10 October 2026  
**Links:** [Modrinth](https://modrinth.com/resourcepack/smooth-fonts-32x) · [Source and release provenance](https://github.com/ZynAyush/Smooth-Fonts-32x)

Smooth Fonts 32x gives Minecraft’s default text a clean, smooth 32x-style appearance while keeping the familiar vanilla interface. It changes how text across the game UI looks, with the aim of making it easier to read and more consistent.

## Features

- **Default font replacement:** Replaces Minecraft’s default font definition so the game uses the pack’s custom glyph textures instead of the standard font atlas.
- **Chat readability:** Changes chat text to match the pack’s smooth style.
- **Menu and HUD typography:** Menus and other UI elements that use Minecraft’s default font also use the replacement.
- **Unicode glyph coverage:** Includes the standard ASCII font atlas and a broad set of Unicode page textures, covering more than basic English characters.
- **32x visual treatment:** Uses a 32x-style font while keeping the familiar Minecraft look, rather than replacing the full UI theme.

## What it does not do

The pack does not add gameplay mechanics, change chat features, translate text or modify server-side data. It changes how glyphs are rendered on the client. Mods or other resource packs that supply their own font definitions may override or partially replace its changes.

## Installation

1. Download the ZIP from [Modrinth](https://modrinth.com/resourcepack/smooth-fonts-32x/versions).
2. Open Minecraft Java Edition’s Resource Packs menu.
3. Select **Open Pack Folder** and place the ZIP inside.
4. Return to the game, enable Smooth Fonts 32x, and place it above other packs that replace the same font files.
5. Check chat, menus and the language characters you commonly use.

## Compatibility and release notes

The source-tracked 1.2 release lists Minecraft Java 1.20–1.21.x, snapshots and 26.1–26.3. Check Modrinth’s Versions page for the precise list and current release. The repository’s `pack/` directory is an extracted copy of the published pack, not the editable font authoring project. The original ZIP is retained in `releases/1.2/`.

## Troubleshooting

- **Font did not change:** Confirm the pack is enabled and placed above other font packs.
- **Only some text changed:** Some mods and resource packs provide their own font definitions and can override the default font.
- **Missing or unusual characters:** Test the language or character set in question, and check the current release notes for compatibility.
- **Pack format warning:** Install the release matching your Minecraft version from Modrinth.
