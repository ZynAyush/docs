NETHERITE STONES / ORES

A unified Netherite look for supported stone and ore textures, using Netherite Block textures to give affected blocks a consistent appearance.

01 / OVERVIEW

Netherite Stones / Ores is a Minecraft Java resource pack that replaces supported stone and ore appearances with Netherite Block textures for a uniform visual theme.

Its changes are client-side visuals only. The pack does not modify server-side block data or world generation.

02 / FEATURES

  • Replaces supported stone and ore appearances with Netherite Block textures.
  • Gives affected blocks a consistent look.
  • Client-side visual change; no server-side world-generation changes.

03 / INSTALLATION

  1. Download the ZIP from the Modrinth project page or this repository.
  2. Place it in your Minecraft .minecraft/resourcepacks folder.
  3. Open Minecraft's Resource Packs settings.
  4. Enable Netherite Stones / Ores. Adjust its priority if you use other packs that edit the same textures.
  5. Use the Modrinth versions tab to check supported Minecraft Java versions.
