## Projects

- [Carpet Fake Players](projects/carpet-fake-players.html) — Paper/Purpur fake-player management, ownership, actions, inventories, persistence, physics, permissions, configuration and commands.

### Resource packs
- [ZeroXFog](projects/zeroxfog.html) — removes dimensional and distance fog, including supported Sodium shader paths.

## Accuracy note

A resource pack changes client-side presentation; it does not change server world generation or server block data. Compatibility lists can change between releases, so check each project's Modrinth Versions page before installing. The `pack/` folders in the source repositories are extracted release contents, not necessarily the editable authoring project. See each project's source repository for release provenance and checksums.
