## Source and site files

- `index.html` and the route folders contain the public pages.
- `style.css`, `docs.css` and `community.css` define the visual styles.
- `site-ui.js`, `theme.js` and `water.js` handle the interactive parts of the site.
- `docs/guides/` contains installation and troubleshooting notes.
- `docs/projects/` contains the longer project references.

Project licences and source code remain in their respective project repositories. Check each Modrinth page for the latest files and supported Minecraft versions.
