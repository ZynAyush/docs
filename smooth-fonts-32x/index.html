SMOOTH FONTS 32X

A custom font resource pack that replaces Minecraft's default font with a smooth 32x style while keeping a familiar vanilla appearance.

RESOURCE PACK32X STYLEUI & CHAT
GET ON MODRINTH ↗SOURCE CODE ↗REPORT A BUG ↗FAQ ↗

01 / OVERVIEW

Smooth Fonts 32x gives Minecraft's default font a clean 32x treatment. It aims to make text clearer in menus and chat while keeping a familiar vanilla feel.

02 / FEATURES

  • Replaces the default font with a resource pack.
  • Uses a smooth 32x style.
  • Aims to make UI text clearer in menus and chat.
  • Keeps a familiar vanilla appearance.

03 / INSTALLATION

  1. Download the ZIP from the Modrinth project page or the source repository.
  2. Place the ZIP in your Minecraft .minecraft/resourcepacks folder.
  3. Open Minecraft’s Resource Packs settings.
  4. Enable Smooth Fonts 32x. If another pack also changes fonts, adjust the pack priority to choose which font to use.
  5. Check the Modrinth versions tab for supported Minecraft Java versions.
