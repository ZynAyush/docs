01 / A LITTLE ABOUT ME

I'm an independent Minecraft developer and creator who enjoys working across both sides of the game: server software that helps communities run smoothly, and client-side projects that improve how the game looks and feels.

Most of my hands-on work revolves around Java, Fabric, Paper and Purpur. I like understanding how a feature works under the hood, building it into something usable, then polishing the configuration, documentation and release experience so other people can actually use it.

This archive is where I keep that work organised. It brings together project pages, source repositories, downloads, guides and updates in one place.

04 / HOW I LIKE TO BUILD

  • Useful first. A feature should solve a real problem or make an experience better.
  • Clear by design. Commands, settings and documentation should make sense to the people using them.
  • Test, then polish. Compatibility, edge cases and performance matter just as much as the main feature.
  • Build in public. Feedback, bug reports and ideas help guide what gets improved next.
